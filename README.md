# Sensor Systems (Politecnico di Milano a.a. 2025/2026)
### Course Description
The **SENSOR SYSTEMS** course held at Politecnico di Milano provides theoretical basis on sensors (light and image sensors, temperature sensors, magnetic field sensors, strain and force sensors, displacement, distance and proximity sensors, microphones) and for designing analog and digital front-end circuits. The practical part tackles specific tools to program and debug **ARM microcontrollers**. Projects regard microcontrollers, using the main peripherals (GPIO, SPI, I2C, USART, PWM, ADC) and a sensor expansion board, for developing both the firmware and the proper hardware configuration, to test the conceived embedded system. The goal of the course is to enable master degree Students to select the best sensor for a specific application, develop an optimized front-end circuit and acquire the output signal with a microcontroller.

**All design laboratories use the NUCLEO board by STMicroelctronics, including a 32-bit STM32 microcontroller.**

### Technical Details
*   Microcontroller: **STM32F401RE (ARM Cortex-M4)**
*   Development Board: **NUCLEO-F401RE**
*   IDE: **STM32CubeIDE / STM32CubeMX**
*   Language: **Embedded C**
